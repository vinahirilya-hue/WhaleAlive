# 序列帧查看器

双击项目根目录 `Start-FrameViewer.cmd`，或在浏览器打开本目录 `index.html`。不需要安装依赖，无上传、无外部 CDN。

1. 导入多个 PNG 或整个文件夹（会包括子目录内的 PNG），按文件路径中的数字自然排序。
2. 点击缩略图检查该帧；取消“保留”勾选后，播放将跳过它。可排除连续区间、反选、全部恢复或撤销筛选。
3. 调整 FPS、循环、背景、显示大小。左右按钮跳到上一/下一保留帧；进度条包含所有原始帧，方便恢复。
4. 保存筛选方案 JSON。下次先导入同一组原始图片，再载入 JSON。刷新页面不会自动保留已导入文件。
5. 导出 ZIP，内含按顺序重新编号的保留 PNG 和 animation.json（FPS、循环、原始文件名映射）。图片内容不变。

快捷键：页面空白处聚焦时，空格播放/暂停，左右方向键逐帧，X 或 Delete 排除/恢复当前帧。控件聚焦时优先保留其原生键盘行为。

可以导入任意按帧排序的 PNG 序列试用；文件名中的数字会用于自然排序。
